# 인원별 handoff

각자 맡은 범위. 세부 방법은 담당자가 정하고, 바뀐 내용은 자기 파일에 갱신한다.

| 담당 | 역할 | 파일 |
|---|---|---|
| 차은호 | 실행기 | [runner.md](runner.md) |
| 조정민 | 검사·출력 | [checks.md](checks.md) |
| 정순준 | 환경·성능·사용자 평가·문서 | [env.md](env.md) |
| 김영모 | 테스트·평가 | [test.md](test.md) |

## 맞물리는 지점

- 수동 복구 문서·testenv(환경) → 실행기·검사 개발 시작
- 검사 컨테이너 계약: 실행기·검사가 합의
- 고장 백업(테스트), 대용량 데이터셋(환경) → 평가
